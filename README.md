# Uptime Monitor

This is a beginner-friendly Python project that checks if websites are up or down and logs their status.

## 🔧 Technologies Used

- Python 3
- Requests module

## 🚀 How It Works

- Script loops through a list of websites
- Uses HTTP GET requests to check availability
- Logs and prints whether each site is up or down

## 📦 How to Run

```bash
python monitor.py
